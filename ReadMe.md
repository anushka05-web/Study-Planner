# 🌸 Study Planner

A beautifully designed **Kawaii-inspired Study Planner** built using **HTML, CSS, and Vanilla JavaScript**. This project helps students stay organized with a clean and aesthetic interface featuring a **Pomodoro Timer**, **To-Do List**, **Music Player**, and **Study Notes** — all wrapped in a soft baby pink theme inspired by cute digital planners.

## ✨ Features

- 🎀 Beautiful Kawaii UI (Baby Pink & White Theme)
- ⏳ Pomodoro Study Timer
- ✅ Interactive To-Do List
- 🎵 Built-in Music Player
- 📝 Study Notes Section
- 📅 Daily Study Planner
- 🌸 Responsive Design
- 💾 Local Storage Support (Tasks remain saved after refresh)
- ✨ Smooth Animations and Hover Effects
- 📱 Mobile-Friendly Layout

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
